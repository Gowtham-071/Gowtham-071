# 🚀 Key Projects

### 🔒 AI-Financial Document Fraud Detection System
*Python · CNN · OCR*

* Built a four-stream multi-modal system combining CNN visual forensics, triple-OCR consensus (Tesseract, EasyOCR, PaddleOCR), arithmetic semantic validation, and vendor registry checks
* Achieved **85.0% accuracy and 0.926 AUC-ROC** on a 3,786-invoice benchmark, cutting average audit time per invoice from over 9 minutes to under 30 seconds
* Built a vendor registry layer to catch impersonation attacks that visual and semantic checks alone let through undetected
* **Research accepted for publication at IEEE ICDCA 2026**
